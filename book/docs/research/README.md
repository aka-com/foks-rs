# Research notes

Working notes produced while surveying `foks-rs` for the book, one per area.
Each records the techniques found, with `file:line` pointers into the
`foks-rs` source as of commit `2ff09187` (2026-09-22) and candidate external
references (some marked `[VERIFY]`). The chapters were written from these
notes and then checked against the source again; where a note and the code
disagreed, the chapter follows the code. Treat the notes as a map for
maintaining the book, not as a source of truth.

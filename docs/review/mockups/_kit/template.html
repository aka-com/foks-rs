Today · chat

Household #general as the app draws it today: chat-screen.tsx, chat-teams.tsx and chat-thread.tsx. The thread is Kit.render.thread('household/general'); the rest is static markup copied from the app's DOM.

Findings (format example)

  • TPL-01Ships on today's data
    Team marks in Chat use the app's hue(name), so Household is red here and green in the Files tree, which colours stores by storeHues. Kit.data keeps both as hue and fileHue.
  • TPL-02Needs agent/IPC
    Unread counts in the channel rows and on the rail come from the agent's chat inbox; changing what they count needs agent work.
  • TPL-03Needs protocol/server
    #incidents is readable by admins and owners only (3 readers). Any audience other than "everyone" or "admins and owners" needs server support.
  • TPL-04Deferred
    Edit channel and Delete channel are disabled in the channel context menu ("not implemented").

Try

  • Right-click a channel, or focus it and press Shift+F10.
  • New chat opens the Create channel sheet; Esc closes it.
  • The info button opens Channel info.
  • Press for the search palette.
  • Narrow the window below 760px: the rail becomes icons and the panel button opens the channel drawer.

Kit gallery

Every kit component, each labelled with its classes. Ported components keep the app's class names and values; the toggle switch, styled select, popover surface, tooltip and .kit-split are kit-only and should appear only where a mockup proposes them.

The overlay demo window shows the interaction contract: menus and popovers open on click and close on Esc or an outside click; menus take arrow keys; context menus open on right-click, Shift+F10 or the ContextMenu key; dialogs trap focus; focus returns to the trigger.
